# MileStone

MileStone는 개인 프로젝트와 팀 프로젝트를 한곳에 정리하고, 타임라인과 이력서까지 함께 관리할 수 있는 iOS 포트폴리오 앱입니다.

## 소개

- 프로젝트 제목, 설명, 역할, 팀 규모, 기술 스택을 기록할 수 있습니다.
- 프로젝트별 이미지, 링크, 메모, 태그를 추가할 수 있습니다.
- 프로젝트 진행 이력을 타임라인으로 확인할 수 있습니다.
- 이력서 PDF를 앱 안에서 보관하고 공유할 수 있습니다.

## 주요 기능

- 프로젝트 목록 조회 및 검색
- 프로젝트 상세 정보 편집
- 프로젝트별 썸네일 및 이미지 관리
- GitHub, Live Site, Figma 링크 저장
- 타임라인 기반 프로젝트 히스토리 확인
- 이력서 PDF 업로드 및 공유

## 지원

앱 사용 중 문제가 발생하거나 문의가 필요한 경우 아래 방법으로 연락할 수 있습니다.

- GitHub 저장소의 `Issues` 탭에 문의 등록
- 지원 이메일: `support@example.com`

출시 전 실제 지원 이메일 또는 공식 문의 채널로 꼭 변경하세요.

## 개인정보 및 저장 데이터

MileStone는 사용자가 입력한 프로젝트 정보와 이력서 PDF를 기기 내에 저장하여 관리합니다.

## 지원 URL로 사용하는 방법

이 `README.md` 파일을 GitHub 저장소 루트에 올린 뒤, 아래와 같은 주소를 App Store Connect의 Support URL에 입력하면 됩니다.

`https://github.com/<your-account>/<your-repo>`
